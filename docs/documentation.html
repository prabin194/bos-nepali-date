Documentation

Complete API reference and usage guide for bos-nepali-date — a React component for selecting Bikram Sambat (Nepali) dates with a pluggable conversion engine.

Getting started

bos-nepali-date is a React component for selecting Bikram Sambat (BS) dates. It ships with a pluggable conversion adapter so you can use the built-in tables or bring your own.

Styles are auto-imported — the component imports its CSS as a side effect. If your bundler strips CSS side effects, import styles explicitly: import 'bos-nepali-date/style'.
// Install
$ npm install bos-nepali-date

Basic usage

Wire up the component with a controlled value and an onChange handler. The defaultAdapter includes demo data for 2080–2081 BS.

import { useState } from "react"
import { NepaliDatePicker, defaultAdapter } from "bos-nepali-date"

function Demo() {
  const [value, setValue] = useState(null)

  return (
    <NepaliDatePicker
      value={value}
      onChange={setValue}
      adapter={defaultAdapter}
    />
  )
}

The onChange callback receives a BsDate object or null (when cleared).

// BsDate shape
{
  year: number, // e.g. 2080
  month: number, // 1–12
  day: number // 1–32
}

Core props

onChange required(date: BsDate | null) => void—Fired on selection or clear.
adapter optionalBsAdapterdefaultAdapterConversion engine for BS↔AD arithmetic.
minDate optionalBsDate—Earliest selectable date.

showLabel optionalbooleanfalseRender a visible label above the input.

className optionalstring—Extra class for the root wrapper.
Note: minDate and maxDate clamp the selectable range. They combine with disable rules — if any rule matches, the date is not selectable.

Disable options

Pass a disable object to control which dates cannot be selected.

PropertyTypeDefaultDescription
disable.todaybooleanfalsePrevent selecting today's date.
disable.dateBsDate—Disable a single specific date.
disable.datesBsDate[][]Disable a list of dates.
disable.beforeBsDate—Disable all dates before this.
disable.afterBsDate—Disable all dates after this.
 
// Example: disable today + block specific dates
<NepaliDatePicker
  disable={{
    today: true,
    dates: [
      { year: 2081, month: 1, day: 1 },
      { year: 2081, month: 1, day: 15 },
    ]
  }}
/>

Menu / Display options

Pass a menu object to control locale, calendar layout, and visibility of controls.

PropertyTypeDefaultDescription

menu.showMonthbooleantrueShow/hide the month selector dropdown.
menu.showYearbooleantrueShow/hide the year selector dropdown.
menu.firstDayOfWeek0 | 10Start the week on Sunday (0) or Monday (1).
 
// Example: Nepali locale with Monday start
<NepaliDatePicker
  menu={{
    lang: "ne",
    firstDayOfWeek: 1,
    showMonth: true,
    showYear: true,
  }}
/>

Localization

Set menu.lang="ne" to render month names, weekday abbreviations, and calendar digits in Nepali (नेपाली). The onChange value still returns the date in ASCII BS YYYY-MM-DD format.

OptionLabelsDigitsValue format
menu.lang="en" (default)English month/day names0–92081-01-15
menu.lang="ne"नेपाली month/day names०-९२०८१-०१-१५ (display) / 2081-01-15 (value)
Note: The input accepts Nepali digits (०-९) and normalizes them to ASCII automatically.

/* Example: custom theme */
.np-picker {
  --np-font: "Noto Sans", sans-serif;
  --np-popover-min-width: 300px;
  --np-popover-max-width: 360px;
}
Inherited font: The picker inherits the host app's font family. If you need to force a specific font (e.g., a Nepali-capable font), set --np-font on the wrapper or .np-picker class.

Adapter

The adapter is the conversion engine that translates between Bikram Sambat (BS) and Gregorian (AD) dates. The library ships with a defaultAdapter and a MemoryBsAdapter for custom year tables.

defaultAdapter

Pre-configured with demo data for BS years 2080–2081. Suitable for evaluation and development. Not recommended for production — toAD() and toBS() will throw for dates outside this range.

MemoryBsAdapter

Create a custom adapter with your own complete year table.

import { MemoryBsAdapter } from "bos-nepali-date"

const adapter = new MemoryBsAdapter({
  anchorBs: { year: 2000, month: 1, day: 1 },
  anchorAdIso: "1943-04-14",
  yearTable: {
    2080: [31, 32, 31, 32, 31, 30, 30, 30, 29, 30, 29, 31],
    2081: [31, 31, 31, 32, 31, 31, 30, 29, 30, 29, 30, 30],
  },
})
Note: To use in production, you'll need to provide a complete BS year table (2000–2100 recommended). The published NPM package only includes demo data for 2080–2081.

Creating a custom adapter

Implement the BsAdapter interface to provide your own conversion logic:

// BsAdapter interface
{
  toAD: (date: BsDate) => AdDateIso
  toBS: (date: AdDateIso) => BsDate
  addDays: (date: BsDate, days: number) => BsDate
  diffDays: (date1: BsDate, date2: BsDate) => number
  today: () => BsDate
  range?: { min?: BsDate; max?: BsDate }
}

Accessibility

  • Keyboard: Escape closes the popover, Tab navigates between controls.
  • Click-outside: Clicking outside the popover closes it automatically.
  • ARIA: Month/year toggles expose aria-haspopup and aria-expanded. Calendar days expose disabled state.
  • Input: Numeric mask enforces YYYY-MM-DD format. Accepts and normalizes Nepali digits automatically.
