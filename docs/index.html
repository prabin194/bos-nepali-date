Why this picker?

Built for React apps that need genuine Bikram Sambat date handling — not an English calendar with Nepali labels.

🇳🇵

True BS dates

Full Bikram Sambat arithmetic, not faked with offsets.

🔌

Pluggable adapter

Swap in your own BS↔AD conversion tables.

🌐

Dual language

Toggle English / नेपाली month names and digits.

⛔

Disable rules

Disable dates, ranges, before/after bounds, or today.

🎨

Custom styling

Theme via CSS variables. Everything overrideable.

♿

Accessible

Esc to close, Tab to navigate, ARIA throughout.
